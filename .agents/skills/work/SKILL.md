# Work

## Overview

Thin entrypoint for the repository autonomous issue workflow. Do not duplicate the workflow here.

## Instructions

1. Read `AGENTS.md`.
2. Read `docs/workflows/agent-task-workflow.md` and follow it as the single source of truth.
3. Treat the supplied issue number or issue URL as the selected work item.
4. Start or resume the existing workflow for that item. Prefer an existing branch and pull request over creating duplicates.
5. Stop and report blockers exactly as the workflow requires. Do not guess missing GitHub data or continue silently.
